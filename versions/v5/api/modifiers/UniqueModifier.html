UniqueModifier

UniqueModifier ⇐ ComparisonModifier

A UniqueModifier re-rolls any non-unique dice values and, optionally that match a given test.

Kind: global class
Extends: ComparisonModifier

  • UniqueModifier ⇐ ComparisonModifier
