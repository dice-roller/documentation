@dice-roller/rpg-dice-roller / presenters / TextPresenter

Class: TextPresenter

Defined in: src/presenters/TextPresenter.ts:60

Plain text output, matching v5: e.g. 4d6: [3, 5, 2, 6] = 16, with flag symbols after each die value and history rolls joined with "; ". It prints the supplied roll's total as-is: newly evaluated rolls round their total to 2 decimal places, but restored totals need not be rounded.

Maths is written without spaces ([4, 2]+3), function arguments are joined with , (max([5],[2])), and group members are joined with , ({[4, 5], [3]-1}). A member with flags (e.g. dropped, or a target success) is wrapped in parentheses: ([6, 3])d. An expression result is presented without notation or a total; an empty history produces "".
