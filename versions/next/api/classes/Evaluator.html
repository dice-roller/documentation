Class: Evaluator ​

Defined in: src/evaluator/Evaluator.ts:90

Walks the AST and builds the result tree.

Evaluation uses the supplied context's roll mode, generator and limits. The same AST can be evaluated in random mode for a roll and in min / max mode for its corresponding totals.

protected applyToFlattenedDice(result, apply): ExpressionResult

Applies apply to the flattened dice of every pool in the result, then writes the dice back into their own pools, in the order apply returned them, and recalculates the result.

Each die is tagged with its pool, so the handler may copy, reorder or remove dice.

evaluateGroup() ​

protected evaluateGroup(node, ctx): GroupResult

Defined in: src/evaluator/Evaluator.ts:194

Evaluates each expression, then applies the modifiers in execution order.

Each handler gets the members, unless its groupHandling says otherwise:

  • flatten: as in v5, a group with a single expression ({4d6+2d8}k2) gives the handler the dice of every pool inside it. The die results are flattened, then the result tree is walked again to write them back into their pools and recalculate everything above them.
  • each-pool: the handler gets each nested group's members and each pool's dice.

rebuildPools() ​

protected rebuildPools(result, replace, transformMembers?): ExpressionResult

Defined in: src/evaluator/Evaluator.ts:311

Walks the result tree, replacing each pool with replace(pool, index) and recalculating the values above it. Pools are visited in notation order.

Pools in a pool's quantity or die arguments aren't visited (they've already been used), nor are pools in nested groups unless transformMembers is supplied.
