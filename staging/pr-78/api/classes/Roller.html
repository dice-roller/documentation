Class: Roller<T> ​

Defined in: src/Roller.ts:40

Rolls notation and keeps a history of the rolls.

For a single roll without a history, use new Roll(notation) instead.

Example ​

ts
const roller = new Roller();
roller.roll("4d6");
roller.roll("2d10+3");
roller.history.total;  // e.g. 27
`${roller}`;           // e.g. "4d6: [3, 5, 2, 2] = 12; 2d10+3: [4, 8]+3 = 15"

import() ​

import(data): Roll<T>[]

Defined in: src/Roller.ts:109

Imports exported rolls (a roll or a whole history, as an object, JSON or base64), and adds them to the history, without rolling.

The data is validated first, so nothing is added if any of it is invalid. Imported rolls share this roller's settings for later re-rolls; re-rolling does not add the new roll to the history.
